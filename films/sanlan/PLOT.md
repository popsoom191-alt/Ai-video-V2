# แสนล้าน · ร่างพล็อต (รอยืนยัน)

**แนวเรื่อง:** เล่าเรื่องแบบคลิปตัวอย่าง (`films/file03/refs/guide_sheet.jpg`) ผู้บรรยายพูดกับคนดูว่า "คุณ…" ตัวละครพูดน้อย ภาพประกอบด้วย HUD การ์ดข้อมูล และการ์ด "กฎ"

**แก่นเรื่อง:** เด็กจนที่ไม่ฉลาด ผิดบ่อย โดนหลอกนับไม่ถ้วน แต่ไม่เคยยอมแพ้ ทุกครั้งที่ล้มเขาจดไว้ จนความผิดพลาดหล่อหลอมให้เขาเก่งจิตวิทยา รอบคอบ มองการไกล วางแผนเก่ง รู้ว่าอะไรควรไม่ควร และชนะคนฉลาดได้ เพราะคนฉลาดคิดเยอะ

**อุปกรณ์เล่าเรื่องประจำเรื่อง:** "สมุดกฎของปั้น" ทุกครั้งที่ล้มหรือโดนหลอก จะมีการ์ดกฎใหม่หนึ่งข้อ (แบบการ์ดกฎในคลิปตัวอย่าง) สะสมไปทั้งเรื่อง เช่น
- "เงินที่ได้ง่าย มีคนจ่ายแทนคุณเสมอ"
- "อย่าถามว่าได้เท่าไร ถามว่าเสียได้เท่าไร"

**HUD (มุมซ้ายบน):** อายุ │ เงินในมือ (฿) │ ครั้งที่ล้ม เช่น "๘ ขวบ │ ฿ ๑๗ │ ล้ม ๐"

## โครงเรื่อง 5 ตอน (ร่าง)
1. **๘ ขวบ · เหรียญบาทของยาย:** บ้านริมคลอง แม่ขายข้าวแกง ยายสอนนับเงินทีละบาท "สักวันผมจะรวยแสนล้าน" ทุกคนหัวเราะ
2. **๑๕ · สอบตก:** เรียนไม่เก่ง นุ่นเพื่อนหัวกะทิช่วยติว แอบขายของในโรงเรียน แล้วโดนพี่โอชวนเข้าแชร์ลูกโซ่ เสียเงินเก็บทั้งหมด → กฎข้อ 1
3. **๒๒ · โดนหลอกทุกแบบ:** ทำทุกงาน โดนหลอกออนไลน์ โดนโกงค่าแรง ล้มแล้วลุกปัดฝุ่น เริ่มจดว่าคนหลอกพูดอะไร ใช้จิตวิทยาแบบไหน → ปั้นเริ่มอ่านคนออก
4. **๒๖ · เฮียกิม:** โรงรับจำนำ ครูคนแรกที่สอนเรื่องความเสี่ยง ความอดทน และการมองการไกล
5. **๓๐ · เกมกับคนฉลาด:** เจรจากับคุณธนา นักลงทุนหัวแหลมที่คิดไว้สิบทาง ปั้นชนะเพราะคิดน้อยกว่าแต่ลึกกว่า และรู้ว่าคนฉลาดจะกลัวอะไร จบที่ก้าวแรกสู่แสนล้าน

## ตัวละคร (ภาพใน `epsanlan.js`, `?ep=sanlan`)
- **ปั้น (๘/๑๕/๒๒/๓๐):** ตัวเอก
- **แม่ · ยาย:** ครอบครัว
- **พี่โอ:** คนหลอก
- **เฮียกิม:** ครู
- **นุ่น:** เพื่อนหัวกะทิ
- **คุณธนา:** คนฉลาด
